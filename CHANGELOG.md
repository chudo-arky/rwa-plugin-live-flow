# Changelog

## [0.17.0] — 2026-08-23

### Добавлено
- **Масштабирование схемы**: кнопки «+ / − / 100 %» в углу схемы, колесо мыши масштабирует к курсору (0.5×–4×), при увеличении схему можно перетаскивать мышью, двойной клик по пустому месту — сброс. Масштаб сохраняется между автообновлениями.
- **Большие парки (30–60 нод)**: схема не ужимается ниже 70 % — холст получает высоту окна и листается колесом; масштабирование при этом — кнопками, `Ctrl/⌘ + колесо` (и пинч на тачпаде) или простым колесом, если схема помещается целиком.
- **Панель инструментов над схемой**: поиск по имени ноды, фильтры «только активные» и «только с трафиком» (в шапке — «показано X из N»), переключатель вида **столбец / колонки**. Настройки запоминаются в браузере.
- **Режим «колонки»**: страницами по 20 карточек с переключением «‹ 1 из 4 ›» рядом с переключателем вида (в подписи — «НОДЫ · 1–20 / 72»); у колонки шины слева и справа, от групп — по одной линии на класс по верхней полосе, стабы шина→карточка по классам, правая шина к выходам по нижней полосе (только к тем, куда реально идут ноды страницы); каскады — по коридору справа. Ни одна линия не проходит сквозь чужие карточки, ничего не обрезается по высоте, при отсутствии выходов правые шины не рисуются.
- Режим «столбец» (по умолчанию) — прежняя раскладка с масштабом и прокруткой; парк больше 50 нод листается страницами по 50 (тот же пейджер, подпись «НОДЫ · 1–50 / 100»).
- **Производительность на больших парках**: схема перерисовывается в DOM только когда изменились данные (а не каждые 5 с), бегущий пунктир идёт шагами (~12 кадров/с вместо 60, при сотнях живых линий — ~6) и только у линий, попадающих в видимую область (остальные стоят, пока их не долистали; пересчёт на скролл/масштаб/resize), штрихи без круглых торцов, слой композитора создаётся только на время перетаскивания.

### Исправлено
- Дубли тегов выходов (один тег в нескольких профилях) больше не рисуются двумя карточками друг на друге.
- В карточке ноды без счётчика пользователей больше не появляется «· undefined».
- Клик по ноде в пролистанной вниз схеме больше не сбрасывает прокрутку холста наверх.

## [0.16.0] — 2026-08-22

Первый публичный релиз. Изменений относительно предыдущих версий нет — это стартовая точка.

### Что умеет плагин
- **Живая схема трафика** внутри remnawave-admin (пункт «Схема трафика», страница `/plugins/live-flow`): пользователи → ноды → выходы, автообновление каждые 5 с, масштаб под размер окна.
- **Группы пользователей по типу сети** слева — «Мобильная сеть», «Wi-Fi / LAN», «Сеть неизвестна» (по `ip_metadata` текущего IP); от каждой группы свои линии к нодам: толщина — число активных этого класса на ноде, бегущий пунктир — идёт VPN-трафик, свой цвет у каждого класса.
- **Ноды в порядке панели** (viewPosition), на карточке — VPN-скорость из счётчиков xray панели и два числа онлайна: реально активных по панели · счётчик ноды (с пингами клиентов с авто-выбором); в тултипе — профиль, инбаунды, сетевая скорость хоста.
- **Выходы из конфиг-профилей** панели (Интернет / Блокировка / WARP / цепочки появляются сами), каскады нода→нода отдельной колонкой.
- **Клик по ноде** — кто на ней сейчас: пользователь (+ Telegram ID, тег), IP (IPv6 с переносом по /64), AS и страна/город, инбаунд, время активности, VPN-скорость пользователя; один пользователь с несколькими IP — одной ячейкой; прокрутка списка не сбрасывается при обновлении.
- **Клик по группе** — сводный список активных этого класса по всем нодам с колонкой «Нода».
- **Живые данные из панели**: фоновый опрос API каждые 15 с (скорость — дельты `trafficUsedBytes`/`usedTrafficBytes`, онлайн — `onlineAt`/`lastConnectedNodeUuid`, окно активности 180 с от текущего времени); при недоступности панели — автоматический фолбэк на синк админки с пометкой в шапке, ошибки опроса — только кодом.
- **Устойчивость**: опрос не накладывается сам на себя, таймауты и backoff, кеш конфиг-профилей и классификации сети, лимит 20 000 пользователей с пометкой `truncated`, безопасные преобразования данных панели и БД.
- **Права и приватность**: `live_flow:view` — схема и агрегаты; `live_flow:view_users` — списки людей (без него UI не предлагает клики, API отвечает 403); JSON с `Cache-Control: private, no-store`; только чтение, внешней телеметрии нет.
- **Русский и английский интерфейс** — язык следует за переключателем админки.
- **Совместимость**: remnawave-admin Plugin API v1 (страница в админке — с 4.5.4, на более старых — standalone `/api/v2/plugins/live_flow/ui`), панель Remnawave 3.x, Python 3.11+, один backend-worker.
